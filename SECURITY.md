# Security Policy

## Supported Versions
Only the latest published release of `devlens-mcp` is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability, please do not open a public issue.
Report it responsibly via GitHub Security Advisories or email the maintainer.
All valid vulnerabilities will be patched promptly with an emergency patch release.
